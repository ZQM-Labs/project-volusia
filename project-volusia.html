API Access

GET /api/indicators

All indicators with source, vintage, unit, and coherence group metadata.

GET /api/executive-summary

Executive briefing with key metrics, trends, and data freshness.

GET /api/status

System status, SLA metadata, refresh cadence, and endpoint index.

GET /api/export/json

Download all indicators as JSON with full provenance metadata.

Data Sources

Census PEP

Population Estimates Program. Annual county population estimates. No API key required.

BLS QCEW

Quarterly Census of Employment and Wages. Employment, establishments, wages by county.

NOAA NCEI

Daily weather summaries. Temperature, precipitation. Station: Daytona Beach Intl Airport.

BLS LAUS

Local Area Unemployment Statistics. Monthly unemployment rate by county.

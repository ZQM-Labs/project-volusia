Three Ways to Contribute

Project Volusia is an open-source intelligence platform for Volusia County, Florida. Contributions are accepted from humans and AI agents through the pathways below.

1. Codebase

Submit code, scripts, tools, data fetchers, or bug fixes. All code is MIT-licensed. Contributions go through GitHub pull requests or direct submission.

Contribute Code API Endpoint

2. Knowledge Base

Share data sources, local knowledge, observations, research, or analysis about Volusia County. Structured and unstructured data welcome.

Share Knowledge API Endpoint

3. Mission & Vision

Help shape Project Volusia's strategic direction. Submit feedback on goals, priorities, methodology, or suggest new initiatives.

Shape Mission API Endpoint

AI Agent API

AI agents and automated systems can contribute programmatically. All endpoints accept JSON and return structured responses.

POST /api/v1/contributions — Submit any contribution
curl -X POST https://volusia.zqmlabs.com/api/v1/contributions \ -H "Content-Type: application/json" \ -d '{ "contribution_type": "tool", "content": { "title": "FDOT Traffic Fetcher", "description": "Fetches traffic count data from FDOT for Volusia County", "code": "import requests...", "language": "python" }, "author_name": "AI Agent", "author_email": "" }'

Response: {"submission_id": "SUB-TOOL-...", "status": "queued", "estimated_review_by": "..."}

GET /api/v1/contributions/{id} — Check submission status
curl https://volusia.zqmlabs.com/api/v1/contributions/SUB-TOOL-20260904120000000000
GET /api/v1/contributions — List recent submissions
curl "https://volusia.zqmlabs.com/api/v1/contributions?limit=10&status=queued"
GET /api/indicators — Read current data
curl https://volusia.zqmlabs.com/api/indicators
GET /api/status — System status
curl https://volusia.zqmlabs.com/api/status

Contribution Types

  • tool — Software, scripts, data fetchers
  • data_source — New public data sources
  • analysis — Research or data analysis
  • map — Geospatial data and map layers
  • report — Reports and briefings
  • community — Local knowledge and observations
  • social_media — Social media intelligence
  • educational — School/college projects
  • direct — Strategic feedback and mission input

Review Process

  • All submissions are reviewed by the Project Volusia Governance Board within 5 business days.
  • You will receive an update at your provided email (if any).
  • Approved contributions are integrated into the codebase or knowledge base.
  • You can check status anytime using your submission ID.

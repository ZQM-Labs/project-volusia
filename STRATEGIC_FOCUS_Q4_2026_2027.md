STRATEGIC FOCUS DECLARATION — Q4 2026 / 2027

Project Volusia — Strategic Commitment
ZQM Labs

---

0. THE DECISION

Effective immediately, ZQM Labs' sole strategic focus for Q4 2026 and
the full calendar year 2027 is growing Project Volusia.

No other ZQM initiative, product, client engagement, or side effort
takes priority over Project Volusia during this period. If something
else wants attention, Project Volusia gets the resources.

This is not a prioritization tilt. It is a single-focus commitment.

---

1. WHY THIS MATTERS

The six existing charter documents (MISSION_STATEMENT.md,
COMMERCE_RESEARCH_RELIABILITY.md, GUIDING_PRINCIPLES_VOLUSIA_COUNTY.md,
OPEN_INTELLIGENCE_DATA_DRIVEN_CHARTER.md, TIMELINE_AND_ROADMAP.md, and
this document) already form a coherent strategic framework. They are
not the work — they are the spec.

What has been missing is the commitment to actually execute against it.

Q4 2026 is Phase 1 Foundation in the roadmap. 2027 covers Phase 1
completion and Phase 2 Access. That is the window this declaration
covers.

Declaring single focus now prevents the most common failure mode:
good documents, scattered attention, no delivery.

---

2. WHAT THIS MEANS IN PRACTICE

2.1 ZQM Labs resources — time, engineering, research, tooling — are
directed at Project Volusia deliverables first.

2.2 Work that does not serve a Project Volusia objective is deferred.
This includes:
  - New client engagements outside the Volusia scope
  - New product ideation unrelated to Volusia
  - Tooling build-outs that do not feed a Volusia deliverable
  - Research not tied to a Volusia stakeholder need

2.3 Existing capabilities ZQM already has (forensics, attestation,
  data tooling, web services, automation) are available to serve
  Project Volusia — they are not competing priorities.

2.4 The six existing docs are the governing framework. This declaration
  does not replace them; it commits to them.

2.5 The December 2, 2026 review is a real checkpoint. By then,
  Phase 1 Foundation work should be underway and demonstrable.

---

3. WHAT PROJECT VOLUSIA GETS

3.1 Engineering capacity. ZQM's technical skills (data pipelines,
  API services, web infrastructure, automation, reporting systems)
  become Project Volusia delivery capacity.

3.2 Research discipline. The market research reliability standards,
  source tier system, and methodology framework in the existing docs
  become enforced practice, not aspirational language.

3.3 Open-source first. The charter's open-source priority,
  open-by-default stance, and tool/data/method publishing commitments
  get actual implementation effort.

3.4 Operational build-out. The five subfolders that currently contain
  only spec catalogs (Tools, Data, Map, Methodology, Report) become
  populated with real assets.

3.5 Stakeholder access. The four constituencies named in the guiding
  principles (business owners, residents, tourists, industry movers)
  begin receiving actual intelligence products, not just planned ones.

---

4. PHASE ALIGNMENT

This declaration aligns with the existing TIMELINE_AND_ROADMAP.md:

PHASE 1: FOUNDATION (2026 Q4 - 2027 Q2)
  - Establish Project Volusia team and governance
  - Audit existing open data assets and gaps
  - Launch baseline data portal with key economic indicators
  - Begin stakeholder interviews across all four groups
  - Publish commerce reliability standards
  - Open-source first internal tools

PHASE 2: ACCESS (2027 Q2 - 2027 Q4)
  - Public data portal v2.0 — searchable, API-driven, mobile-first
  - Business owner dashboards — free, plain-language, actionable
  - Resident data access — community meetings, translated materials
  - Tourist-facing real-time APIs — conditions, availability, events
  - Developer portal — documentation, SDKs, sandbox environment
  - First quarterly economic briefings (public)

The declaration covers both phases. Q4 2026 is the start of Phase 1.
All of 2027 runs Phase 1 completion and Phase 2.
